## About

I'm a first-year student at a technical health institute with a background in
**Python** (completed **Harvard's CS50P**). My goal is to become an engineer who
can build reliable, well-tested software and data models for **medical data**.

I learn by building: every concept goes into a real project, every project lives
in version control, and every ten days I write a progress report that measures
what I can actually write without help, not just hours spent.

> **Privacy first.** Any project involving "patients" uses fully fake, generated
> data. No real patient information is ever used or stored.
